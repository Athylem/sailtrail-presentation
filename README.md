# Sail Trail : présentation Supply Chain Odoo (FIGIM 2A, 2026)

Présentation web autonome, animée, du projet Odoo de l'équipe Sail Trail.

- Ouvrir `index.html` dans un navigateur, ou la version en ligne (GitHub Pages).
- Commandes : → ou clic pour avancer, ← pour reculer, **F** plein écran, **N** notes d'orateur.
- Modifier : éditer `source/slides/*.html` ou `source/deck.css`, puis `python build.py` pour régénérer `index.html`.

Les diapos viennent de la présentation Claude Slides de l'équipe ; `build.py` remplace les images de l'éditeur par les fichiers de `assets/`.
